Recursion is when a function calls itself to solve a smaller instance of the same problem. Every recursive function needs a base case that stops the recursion and a recursive case that moves towards the base case. Example: factorial(n) = n * factorial(n-1), with factorial(0) = 1. Each call is pushed onto the call stack; if there is no base case the stack keeps growing until a stack overflow error occurs. Recursion is natural for trees, divide and conquer (merge sort, quick sort) and backtracking. Any recursive solution can be rewritten iteratively, sometimes using an explicit stack. Tail recursion is when the recursive call is the last operation; some compilers optimise it to use constant stack space.
