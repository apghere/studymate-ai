Data structures notes (Hinglish): Linked list ek linear data structure hai jisme har node ke paas data aur next node ka pointer hota hai. Array ki tarah memory contiguous nahi hoti, isliye insertion aur deletion beginning pe O(1) time mein ho jaata hai. Lekin kisi bhi element ko access karne ke liye shuru se traverse karna padta hai, jo O(n) hai. Doubly linked list mein har node ke paas prev aur next dono pointers hote hain, isliye dono directions mein traverse kar sakte hain. Circular linked list mein last node wapas first node ko point karta hai.
